**Website:** [https://router.bynara.id/](https://router.bynara.id/)

NaraRouter (Bynara) is a multi-model AI gateway: one API key unlocks many models through a single **OpenAI-compatible** endpoint (`https://router.bynara.id/v1`), so iCline talks to it like any OpenAI-compatible provider — no plugin or custom protocol needed.

### Prerequisites

1.  **Create an account:** Sign up at [router.bynara.id](https://router.bynara.id/) (email + password, or continue with Google).
2.  **Generate an API key:** Open the dashboard and create a key. The free-tier quota is active instantly.

### Configuration in iCline

> See [Authorization & Model Selection](/getting-started/authorizing-with-cline#menu) for the general auth flow.

1.  **Open iCline Settings:** Click the ⚙️ icon in the iCline panel.
2.  **Select Provider:** Choose **NaraRouter** from the **API Provider** dropdown.
3.  **API Key:** Paste the key from your NaraRouter dashboard.
4.  **Model:** iCline ships a snapshot of the gateway catalog (56 models, captured 2026-10-02), so the dropdown is already full before you paste a key — default `mimo-v2.5-free`. Once the key is saved, iCline re-fetches the live `/v1/models` list and merges it in, so new gateway models appear without waiting for an iCline update. You can always type a model ID manually too.

> A fresh NaraRouter account must bind its Telegram account, join the required Telegram group/channel, and relink at `/settings` first — until then every API call (including `/v1/models`) answers 403 `telegram_required` and the live refresh stays on the snapshot.

### Tips and Notes

-   **Base URL is fixed** — `https://router.bynara.id/v1`. There is nothing to customize, unlike self-hosted gateways.
-   **Context window** — when the gateway's `/v1/models` response lacks size info for a model, iCline falls back to a 128K context window. Adjust the `Context Window` field in model config if you know the model's real limit.
-   **Anthropic-compatible endpoint** — NaraRouter also exposes an Anthropic-compatible surface, but iCline uses the OpenAI-compatible one; you do not need it.
-   **Billing** — usage bills against your NaraRouter account (free-tier quota refreshes daily). The TaskHeader cost indicator reflects the per-token prices iCline knows; gateway-side pricing wins when the catalog declares it.
-   **Three model shelves** — the dashboard groups models into **Free models** (usable on the Free plan quota; note some still carry PAYG rates, e.g. `agnes-2.5-flash`), **Free for paid users** (served free while you hold the qualifying credit balance — the "Hold above Rp…" threshold drifts, check the dashboard), and **PAYG Models** (billed per token). iCline tags each snapshot model with its shelf (read 2026-10) and shows the note under the model in Settings; anything not on the first two shelves is PAYG. Model **multipliers** (2x, 0.01x, …) only affect plan-quota burn, never PAYG billing.

### Troubleshooting

-   **Model dropdown is empty** — the API key is missing or invalid. Re-paste it from the dashboard and check the free-tier quota is active.
-   **`401 unauthorized`** — same cause: the gateway requires a valid `Bearer` key on every call, including `/v1/models`.
-   **Tool calls don't fire** — the model you picked doesn't support OpenAI-style function calling. Switch to a model with documented tool support.
