กล่อง “Completed” — ตัวเลือกสี

✅ เลือกแล้ว (กล่อง Task Completed): theme blue — ขอบเขตเดิม: ไม่แตะ token success ของทั้งแอป

กล่อง Task Completed — border-completed/20 + bg-completed/10 + text-completed บน token ใหม่ --color-completed: var(--vscode-charts-blue) (ธีมมืด #75BEFF · สว่าง #007ACC)

การ์ด COMPLETED (คำตอบสุดท้าย) — ยังไม่แก้ ใช้ค่าตายตัว: ขอบ rgba(99,102,241,0.3) · พื้น rgba(99,102,241,0.07) (indigo #6366F1) แต่ป้ายใช้ var(--vscode-charts-blue) ⇒ พื้นกับป้ายคนละเฉด และไม่ตามธีม

ส่วนที่ 1 · กล่อง Task Completed — ตัวเลือกทั้งแปด (อันที่เลือกแล้วคือ theme blue)

ส่วนที่ 2 · การ์ด COMPLETED (คำตอบสุดท้าย) — สี่แบบให้เลือก รวมของปัจจุบันไว้เทียบ

การ์ดนี้จะติดสีเฉพาะตอนเป็นรายการล่าสุดและยังไม่ stream — พอมีข้อความใหม่ต่อจากนั้น สีจะหายไปเอง (แต่ละการ์ดมีภาพ “ตอนหลุดจากตำแหน่งล่าสุด” ให้ดูด้านล่าง)

สองแบบที่ต่างกันโดยธรรมชาติ: “ตามธีม” จะเปลี่ยนตามธีมที่ผู้ใช้เลือก อ่านออกเสมอ · “สีตายตัว” ได้สีเดียวกันทุกธีมแต่ต้องเช็คคอนทราสต์เอง
