# ข้อตกลงการทำงานเป็นรอบ (รอบงาน = โค้ด + เอกสาร + commit)

**ตกลงเมื่อ:** 2026-10-16 (maintainer) — หลังพบว่าเอกสารกับ commit ค้างสะสมคนละรอบกับตัวโค้ด
(เช่น งานเสร็จแล้วแต่ changelog/commit ยังไม่ตาม ทำให้รอบถัดไปต้องตามเก็บย้อนหลัง)

## กติกาเดียวที่ต้องจำ

> **งานหนึ่งรอบ ปิดให้จบในรอบเดียว**: โค้ด + เทสต์ + changelog + เอกสารที่เกี่ยวข้อง + commit
> ไปพร้อมกัน และ **รายงานท้ายรอบ** ว่าอะไรทำ อะไรตรวจแล้ว อะไรยังค้าง

ห้ามจบรอบด้วยงานที่ "ทำเสร็จแล้วแต่ยังไม่บันทึก" — ถ้าจำเป็นต้องค้างจริง ๆ
(รอ smoke, รอผู้ใช้ตัดสินใจ, ติด blocker) ให้เขียนไว้ทั้งในรายงานและในเอกสารของรอบนั้น
พร้อมเหตุผล ว่าค้างอะไรและรออะไรอยู่

## เช็กลิสต์ต่อรอบ

1. **โค้ด + เทสต์** — เขียน/แก้ เทสต์ที่ปักพฤติกรรมของรอบนั้น แล้วรันให้เขียวก่อนไปข้อ 2
   (typecheck, lint, unit, e2e ที่เกี่ยวข้อง; เก็บคำสั่งและผลไว้รายงาน)
2. **CHANGELOG** — เพิ่มบรรทัดของรอบใน `apps/vscode/CHANGELOG.md` ใต้หัวรุ่นที่ยังไม่ปล่อย
   (`### Added` / `### Fixed` / `### Changed`) ใช้ป้ายรอบ (`dev.5-fix.6`) ให้ตรงกับ VSIX
   และเขียนว่าเทสต์อะไรปักไว้
3. **เอกสารที่เกี่ยวข้อง** — `docs/icline/*` (pack notes, tracker, ADR/notes ของเรื่องนั้น),
   README ที่มีบรรทัดสรุปฟีเจอร์ — แก้ในรอบเดียวกับโค้ด ไม่ใช่รอบถัดไป
4. **ถ้ารอบนั้นจะส่ง smoke** — bump `apps/vscode/package.json` → `node scripts/sync-icline-docs.mjs`
   (ห้ามข้าม ไม่งั้น About โชว์ป้ายเก่า) → แพ็กตาม `vsix-pack-notes.md` → ตรวจไบต์/ด่าน contract
5. **Commit ทันทีที่รอบจบ** — ข้อความ commit บอก *ทำไม* ของรอบนั้น อย่าปล่อยงานค้างข้ามวัน
   ถ้ามีงานของคนอื่น/เอเจนต์อื่นปนใน working tree ให้ stage เฉพาะไฟล์ของรอบนี้
6. **รายงานท้ายรอบ** — สรุปสั้น ๆ: อะไรส่งมอบ (ไฟล์/คำสั่ง), อะไรตรวจแล้ว (คำสั่ง + ผลตัวเลข),
   อะไรตรวจไม่ได้/ยังค้าง + เหตุผล

## ข้อยกเว้นที่ยอมรับได้

- งานที่รอ **smoke จาก maintainer** — โค้ด/เอกสาร/commit จบในรอบ แต่ป้ายสถานะเป็น "รอ smoke"
- งานที่ต้อง **รอคำตอบผู้ใช้** (เลือกแนวทาง, ยืนยันสิทธิ์, คีย์จากบริการภายนอก) — หยุดที่จุดนั้น
  แล้วรายงานว่า blocked อะไร ไม่ใช่ปล่อยผ่านเงียบ ๆ
- **flake ของเทสต์** — บันทึกไว้ในเอกสารพร้อมหลักฐาน (log/เวลาที่รัน) ห้ามปิดด้วยการ weaken assertion
